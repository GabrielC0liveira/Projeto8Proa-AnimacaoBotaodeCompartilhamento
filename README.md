
# 🔗 Botão de Compartilhamento Animado

Projeto de um botão de compartilhamento interativo, desenvolvido com **HTML5 e CSS3** como parte de uma atividade prática do curso PROA.

O projeto tem como objetivo explorar conceitos de interatividade com CSS, animações e estilização de componentes, utilizando um botão que revela opções de redes sociais ao ser acionado.

## 🖥️ Prévia do projeto

🔗 **[Acesse o projeto online](https://gabrielc0liveira.github.io/Projeto8Proa-AnimacaoBotaodeCompartilhamento/)**

## Funcionalidades e características

- Botão interativo que revela opções de compartilhamento ao ser clicado.
- Exibição de ícones do Facebook, Twitter, Instagram e YouTube.
- Animação de abertura e fechamento do painel de ícones.
- Alteração visual do botão para indicar a opção de cancelar.
- Efeitos hover nos ícones, com movimentação e alteração de cores.
- Interatividade desenvolvida inteiramente com HTML e CSS, sem JavaScript.

## Tecnologias utilizadas

- **HTML5:** estruturação do botão, ícones e controle de seleção.
- **CSS3:** estilização, posicionamento, animações e efeitos interativos.
- **Font Awesome:** utilização de ícones das redes sociais.
- **Google Fonts:** utilização da fonte Poppins.

## Aprendizados

Durante o desenvolvimento, foram praticados conceitos como:

- Estruturação de componentes interativos utilizando HTML.
- Utilização de inputs do tipo `checkbox` para controlar estados visuais.
- Aplicação dos seletores CSS `:checked` e `~` para criar interatividade sem JavaScript.
- Criação de animações utilizando `transition` e `hover`.
- Manipulação de posicionamento, opacidade e visibilidade dos elementos.
- Utilização de pseudoelementos como `::before` para criar detalhes visuais.
- Personalização de ícones com efeitos de transformação e alteração de cores.
